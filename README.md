# Курсовая работа: рекомендательная система на основе графовых подходов

## Тема работы

**Построение рекомендательной системы с помощью графовых нейронных сетей, использующих атрибуты товаров и пользователей**

## Описание проекта

В рамках курсовой работы реализована рекомендательная система для задачи персонализированных рекомендаций товаров. Работа выполнена на примере датасета **H&M Personalized Fashion Recommendations**.

Основная идея проекта заключается в построении рекомендательной системы, которая использует взаимодействия пользователей с товарами, признаки товаров и графовую структуру данных. Пользователи и товары рассматриваются как вершины двудольного графа, а покупки — как связи между ними.

В работе реализован многоэтапный подход:

1. предварительный анализ и подготовка данных;
2. формирование признаков пользователей и товаров;
3. построение графового представления данных;
4. генерация кандидатов для рекомендаций;
5. ранжирование кандидатов;
6. сравнение нескольких моделей и подходов;
7. оценка качества рекомендаций с использованием метрики MAP@12.

## Реализованные подходы

В ходе работы были рассмотрены и сравнены несколько подходов к построению рекомендаций:

- Popularity baseline;
- Repurchase baseline;
- Item-based collaborative filtering;
- графовый подход на основе взаимодействий пользователей и товаров;
- GNN/LightGCN-подход для генерации кандидатов;
- LightGBM-модель для финального ранжирования.

## Метрика качества

Для оценки качества рекомендаций использовалась метрика:

**MAP@12** — Mean Average Precision at 12.

Эта метрика подходит для задачи рекомендаций, поскольку оценивает не только наличие релевантных товаров в списке рекомендаций, но и их позиции в выдаче.

## Итоговый результат

В результате экспериментов была построена рекомендательная система, объединяющая графовую генерацию кандидатов и ранжирование с помощью модели машинного обучения.

Лучшее качество было получено при использовании гибридного подхода с финальным ранжированием кандидатов.
